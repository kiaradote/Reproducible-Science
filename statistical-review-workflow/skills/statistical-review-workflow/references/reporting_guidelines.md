# Reporting guidelines (pick by study type)
- CONSORT: randomized trials. STROBE: observational. ARRIVE: animal studies. PRISMA: systematic reviews/meta-analyses. TRIPOD(+AI): prediction models. STARD: diagnostic accuracy. REMARK: tumor markers. MIQE: qPCR. MINSEQE/MIAME: sequencing/array. MDAR: life-science general. SAMPL: statistics reporting in biomedical papers. CHEERS: economic evaluations.

Items that most affect statistical interpretation (check for every study):
1. Definition of the unit of replication and n per group/claim
2. Sample size rationale; stopping rule
3. Randomization/blinding/allocation
4. Exclusions, filtering, missing data handling, and when thresholds were set
5. Exact tests/models, software + version, test sidedness, multiplicity handling
6. Effect sizes with CIs; exact p-values; error bar definition
7. Raw data and code availability with accessions
8. Prespecification/registration status
